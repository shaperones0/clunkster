Overview¶

  • clunkster - Separate Game Maker 8.2 projects into clusters.

    • clunkster.asset - Abstract asset type and builtin definitions.

    • clunkster.lint - Linter system.

    • clunkster.project - Read cacher.

    • clunkster.analyze - Project analysis routines.

      Facilitates building dependency graph.

      • clunkster.analyze.scan_dep - Routines for scanning text files for dependencies.

    • clunkster.parse - GameMaker8.2's text data parsing.

      • clunkster.parse.gml - GML script static analysis.

        The purpose of the analysis is to find "guard scripts", like this: ... 

        if room_is_stageA() {
    ...
}
        anything inside this should be considered as only "referrable" if current room is a part of stageA cluster.

      • clunkster.parse.index - Parse index.yyd files.

      • clunkster.parse.kv - Parse GameMaker 8.2 key=value metadata files.

      • clunkster.parse.tree - Parse tree.yyd files.

    • clunkster.pipeline - Pipeline bones.

      Contains a system of tasks and executors, events and UI abstractions.

      • clunkster.pipeline.cache - Build progress caching.

      • clunkster.pipeline.task - Pipeline task.

      • clunkster.pipeline.events - Pipeline event system.

        • clunkster.pipeline.events.context - Task's execution context.

        • clunkster.pipeline.events.dispatcher - Event dispatcher.

        • clunkster.pipeline.events.event - Pipeline builtin events.

        • clunkster.pipeline.events.sink - Event sink.

          Event sinks are used by workers as a place to post messages concerning ...

          themselves about communication intricacies.

      • clunkster.pipeline.executor - Task executors.

        • clunkster.pipeline.executor.base - Common executor utils.

        • clunkster.pipeline.executor.mp - Multiprocessing executor.

        • clunkster.pipeline.executor.thread - Threading executor.

      • clunkster.pipeline.ui - Pipeline UI abstractions.

        • clunkster.pipeline.ui.adapter - Sink adapter for ease of use.

        • clunkster.pipeline.ui.base - UI abstraction.

        • clunkster.pipeline.ui.simple - Simple print-based Ui.

    • clunkster.text - Generic text tools.

      • clunkster.text.line - Source line map.

      • clunkster.text.location - Source navigation model.
